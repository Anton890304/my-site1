# Визитка Антона

Статичный одностраничный сайт без сборки. Для публикации на GitHub Pages:

1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки.
2. В **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
3. GitHub покажет адрес опубликованного сайта через несколько минут.

Чтобы CTA внизу сайта вёл в конкретный мессенджер, добавьте вашу ссылку в `index.html` или сообщите её — я подключу кнопку.
